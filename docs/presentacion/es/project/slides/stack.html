SONORA · NASA Space Apps 2026

SONORA está hecho en .NET, con Blazor WebAssembly en el navegador y ASP.NET Core en el servidor. El audio se genera en tiempo real con Tone.js y se puede grabar sin salir del navegador. La voz usa la Web Speech API y un asistente de OpenAI para las frases que no reconocen las reglas. Todo cabe en un hosting gratuito de 200 MB.
