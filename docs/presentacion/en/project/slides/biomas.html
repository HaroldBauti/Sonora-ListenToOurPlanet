SONORA · NASA Space Apps 2026

For the Earth System Trend Detective challenge we added two tools about Peru. The first is an atlas: a neural network classifies eight biomes from MODIS, SRTM and IGBP data from NASA GIBS, from 2001 to 2024, and each map uses four exact colors, one per musical layer. The second lets you hear how the climate of eleven regions has changed since 1981: a network trained on 199 regions worldwide suggests which variables are changing, and we show the real Mann-Kendall test result next to it.
