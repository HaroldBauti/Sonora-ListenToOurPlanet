SONORA · NASA Space Apps 2026

SONORA is built with .NET: Blazor WebAssembly in the browser and ASP.NET Core on the server. The audio is generated in real time with Tone.js and can be recorded without leaving the browser. Voice uses the Web Speech API, plus an OpenAI assistant for sentences the rules don’t recognize. Everything fits in a free 200 MB hosting plan.
